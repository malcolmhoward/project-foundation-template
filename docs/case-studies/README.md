# Case Studies

This directory is reserved for documenting real-world success stories from projects that have adopted Project Foundation Template.

## Purpose

Case studies serve multiple purposes:

1. **Validation** - Demonstrate that the governance principles work in practice
2. **Guidance** - Show how different types of projects apply the templates
3. **Inspiration** - Help new adopters understand the possibilities
4. **Feedback Loop** - Document improvements that feed back into the template

## Structure

Each case study should follow this format:

```
case-studies/
├── README.md                    # This file
├── template.md                  # Template for new case studies
└── [project-name]/
    ├── overview.md              # Project summary and context
    ├── implementation.md        # How they adopted PFT
    ├── outcomes.md              # Results and lessons learned
    └── assets/                  # Screenshots, diagrams, etc.
```

## Submission Guidelines

To submit a case study:

1. **Timing** - Projects should have at least 3 months of governance experience
2. **Permission** - Obtain written permission from project maintainers
3. **Anonymization** - Sensitive details may be anonymized if needed
4. **Verification** - Claims should be verifiable or clearly marked as subjective

## Categories

Case studies may fall into these categories:

| Category | Description |
|----------|-------------|
| **Open Source** | Public repositories with community governance |
| **Enterprise** | Internal projects within organizations |
| **Educational** | Learning projects, bootcamps, courses |
| **Non-Software** | Organizations using governance principles for non-code projects |
