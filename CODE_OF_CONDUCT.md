# Code of Conduct

## Our Pledge

We pledge to make participation in our community a harassment-free experience for everyone.

As a governance template project, we hold ourselves to the same ethical standards we ask of our users. This Code of Conduct is grounded in [Principle Zero](ETHICS.md): "Do No Harm, Allow No Harm."

## Our Standards

Examples of positive behavior:
* Using welcoming and inclusive language
* Being respectful of differing viewpoints
* Gracefully accepting constructive criticism
* Focusing on what is best for the community
* Showing empathy towards other members

Examples of unacceptable behavior:
* Harassment of any kind
* Discriminatory language or actions
* Publishing others' private information
* Other conduct which could reasonably be considered inappropriate

## PFT-Specific Expectations

As contributors to a governance template project:

* **Educational focus**: Help others learn, don't gatekeep knowledge
* **Ethical awareness**: Consider downstream impact of templates on thousands of projects
* **Constructive criticism**: Template improvements require honest feedback
* **Attribution respect**: Acknowledge sources and inspirations appropriately

## Enforcement

**Enforcement Contact**: Create a GitHub issue with the label `conduct` or contact the maintainer directly via the repository's GitHub Discussions.

**Response Process**:
1. Report is received and acknowledged within 72 hours
2. Maintainer reviews the report privately
3. Appropriate action is determined based on severity
4. Outcome is communicated to reporter (and respondent if appropriate)
5. Appeals may be submitted within 14 days

**Possible Actions**:
* Warning (private or public)
* Temporary ban from project spaces
* Permanent ban from project spaces
* Report to platform (GitHub) for severe violations

## Scope

This Code of Conduct applies within all project spaces (repository, discussions, issues, pull requests) and in public spaces when representing the project.

## Acknowledgment

This Code of Conduct expects contributors to understand that:
* A governance template influences thousands of downstream projects
* Ethical behavior here sets the standard for users of our templates
* Our community's health directly affects the quality of governance we can provide
